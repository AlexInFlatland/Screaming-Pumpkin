# Screaming Pumpkin for Halloween

Arduino code for a pumpkin that screams at people walking by. It uses an Arduino Uno, an Adafruit Music Maker Shield, an ultrasonic sensor and a sound sensor.

- `Talking_Pumpkin/Talking_Pumpkin.ino`: Arduino sketch

Video: https://youtu.be/8Z0-s5L49Q4

Project page and parts list: https://alexinflatland.com/projects/how-to-make-a-screaming-pumpkin-for-halloween-to-scare-your-unsuspecting-neighbors/
